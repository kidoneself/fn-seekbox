# 网盘转存与持续追更

1.4.1 在原有转存与追更上增加首页账号卡片、三家网盘扫码连接和项目侧栏。支持百度、夸克、迅雷的同网盘转存；不会把百度分享转存到夸克，也不会下载文件到 NAS。

## 使用

1. 从飞牛桌面进入应用，点击首页「我的网盘」中的「扫码登录」，或顶部「我的网盘」，连接自己的网盘账号。飞牛登录用于隔离每个人保存的账号和追更任务；实际转存使用所选网盘账号。
2. 搜索资源。百度、夸克、迅雷的结果行及详情提供两个操作：
   - **转存到网盘**：选择账号和目标文件夹，确认后转存当前分享的全部文件，只执行一次。
   - **追更**：选择账号、目标文件夹及检查间隔，先转存现有文件，之后持续检查同一分享里的新增文件。
3. 在「我的追更」查看最后检查时间、下次检查时间、累计保存数量及错误，修改间隔、立即检查、暂停或移除。
4. 在「转存记录」查看排队、执行中、完成、失败、部分完成或中断状态。关闭页面后，NAS 上的应用仍会处理任务；应用停止时不执行。

检查间隔为 15～1440 分钟，默认 60 分钟。从上次检查结束计算下一次时间；后台每 30 秒检查队列，任务按顺序执行，繁忙时会延后。暂停会在当前网盘请求结束后阻止后续文件写入。移除追更或断开账号不删除网盘文件；运行中的任务需先结束，关联追更需先移除，才能断开账号。

## 连接自己的网盘账号

默认使用对应网盘 App 扫描官方登录二维码，在手机上确认后，页面校验账号并保存。可填写账号备注；二维码过期可以重新生成。关闭窗口或切换网盘会取消当前登录，重新连接会核对原账号身份。

扫码在 NAS 内完成：百度、夸克使用官方登录接口，迅雷使用隔离的无头 Chromium 登录页面。浏览器只接收二维码和状态，不接收登录 Cookie 或令牌。未完成会话过期清除；不依赖第三方扫码中转服务，也不需要在本应用输入网盘密码。

「手动导入」作为备用方式，导入本人已登录会话，服务端真实校验通过后才保存：

| 网盘 | 接入方式 | 失效处理 |
| --- | --- | --- |
| 百度 | 本人网页完整 Cookie；需包含有效登录信息 | 重新连接原账号 |
| 夸克 | 本人网页完整 Cookie；同时验证网页登录和网盘 API，并识别账号 ID | 重新连接原账号 |
| 迅雷：请求头 | 本人网页请求的 access_token、captcha_token、device_id、client_id | 不含续期信息，失效后重新连接 |
| 迅雷：完整会话 | 本人 web_session JSON，含 access_token、refresh_token、expires_at、headers，captcha_meta 可选 | 有效刷新令牌可续期；验证令牌续期还需要本人会话中的有效元数据，遇人工验证或无法续期时重新连接 |

百度与夸克可在自己已登录的官方网站浏览器开发者工具「网络」中，查看对应网盘请求的 Cookie。迅雷请求头字段说明显示在连接表单中；完整会话模式适用于已经通过本人登录流程获得该 JSON 的用户，不会自动从浏览器读取或替用户生成有效凭据。`expires_at` 为 RFC3339 时间字符串；`headers` 包含 `x-device-id`、`x-client-id`、`x-captcha-token`，字段名不区分大小写。

手动导入的凭据只在连接表单中短暂存在，提交或关闭后清空，不写入浏览器本地存储，不通过列表接口返回。服务端使用 AES-GCM 加密保存，账号操作串行，续期后的凭据先持久化再继续请求。重新连接会核对稳定网盘账号 ID；若换成另一个网盘账号，应新增账号，不能沿用原账号的追更进度。

## 转存与恢复规则

- 先完整读取分享，再按原有目录层级逐个保存文件；不会把未读完整的分享当成完整结果。分享枚举限制为 10000 项，另有分页和递归深度限制。
- 目标文件夹按路径从网盘根目录核对；路径被删除、同名目录有歧义或路径已指向其他目录时停止，不向错误位置写入。
- 按用户、账号、分享、目标目录、文件标识及版本记录已完成内容，重复检查跳过已成功保存的文件。一次转存后对同一分享和目录开启追更，会复用已有记录。
- 不覆盖目标同名文件。来源同名内容发生变化或目标已有未登记的同名文件时，显示冲突，需要用户处理；没有自动洗版、重命名覆盖或影视集数识别。
- 只有网盘返回确定成功才记录完成。先登记写入意图再请求网盘；请求提交后遇超时、断网或令牌失效，保留「结果未确认」，后续不会盲目重复写入。请到网盘核对实际文件，必要时重新选择保存目录；本次没有提供自动核销不确定结果的界面。
- 服务重启后恢复排队任务，将中断的运行记录标记为中断；保留成功记录及不确定写入记录。
- 当前跟踪原分享，不会按片名自动搜索替代来源，不会自动下载到 NAS，也没有外部消息推送。分享失效、空间不足等问题显示在任务和追更记录中。
- 本地完成记录是转存历史，不是远端库存镜像；在网盘中手动删除已保存文件后，不承诺自动补回。

每个飞牛用户最多连接 30 个账号、添加 100 个追更，最多等待 50 个任务。界面保留最近约 200 个任务记录，逐文件去重记录独立保留。

## 数据与开发

默认数据目录为搜索缓存目录的同级 `cloud/`。飞牛典型路径是 `/vol1/@appdata/fn-seekbox/data/cloud/`，可通过 `SEEKBOX_CLOUD_PATH` 指定独立目录。

- `cloud.db`：账号、追更、任务和去重台账，权限 0600。
- `credentials.key`：凭据加密密钥，权限 0600；目录权限 0700。

备份和迁移需同时保留数据库及密钥。数据库存在但密钥丢失时拒绝初始化网盘模块，不自动生成新密钥覆盖；搜索功能仍可运行。运行数据已加入忽略规则，不打入发行包。

后端新增 `cloud` 包及 `/api/cloud` 路由。网关必须可信地传入 `X-Trim-Userid`；后端只接受来自本机的该身份，所有数据按该用户隔离。写请求要求 `X-Seekbox-Action: 1`，请求体为 JSON，大小限制 64 KiB。现有搜索和公开健康接口不增加这些网盘模块专用要求。

前端新增网盘中心、转存弹窗和结果入口，保持现有 Vue 3 组件与样式。源码构建不自动替换 `app/web` 或 `app/bin/seekbox`，发行仍走项目原有打包流程。
