# 1.6.3：远端迅雷扫码

仅在在线更新开发副本实现，原 `fn-pansou` 未因本次扫码中心开发修改。

- 远端中心：`https://hermes.smartloan.cn`，管理入口 `/seekbox-config/` → 扫码中心。
- 独立工作服务源码：`/home/kidoneself/coding-my/drive-scan-center`，支持百度/夸克/UC/迅雷。当前搜盘只对迅雷启用远端；百度、夸克本地扫码保持不变，未新增 UC 转存功能。
- 远端地址沿用管理中心基址；NAS 使用自己加密保存的实例凭证。若尚未登记则按原登记协议获取，不修改运行统计开关。普通页面不会取得 report_token 或网盘凭据。
- 扫码后 NAS 领取完整迅雷 web_session，包括刷新令牌与设备等请求头；先验证、加密保存和原有账号去重，再 ack 通知远端清理。轮询只暴露二维码、状态与排队提示。
- 网络失败有界退避，取消登录清理远端。扫码中心异常会明确失败，不静默切换其他账号，也不删除已经保存的账号。
- NAS 后续网盘请求与刷新仍直连迅雷，远端只承担扫码登录。跨 IP 使用需要真实账号验收。

默认 FPK 不再携带 Chromium；保留 Node 依赖和百度/夸克需要的 JavaScript HTTP 运行库。带浏览器版本仍可通过打包开关生成，`SEEKBOX_REMOTE_XUNLEI=0` 为显式本地回退开关。

1. Go 隔离集成测试：远端返回后验证并持久化再 ack；重复完成不会重复 ack；公开状态不暴露凭据；跨用户拒绝；排队取消不落库并清理远端。
2. 国内机四网盘真实二维码，两路迅雷同时取得二维码，第三路排队可取消。清理后活动、队列、会话均为 0。
3. 管理公网鉴权与动态权限、桌面/手机页面。
4. x86/ARM64 完整 FPK 架构与内容检查；x86 包内后端启动健康检查。
